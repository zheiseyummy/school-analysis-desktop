# 本次对话需求与开发记录

更新时间：2026-09-25  
用途：记录本轮对话中已经确认的需求、实施结果、验证证据和后续交接信息。

## 1. 对话范围

本记录覆盖从单机本地化改造、综合素质评价联调、成绩分析功能扩展，到本次管理字段精简和文档交接的全部确认事项。原始 ZIP、学校真实数据和临时审查输出不作为仓库运行时资源；真实数据只在本机 SQLite 中使用。

## 3. 当前已完成能力

- 单用户免登录和固定本地菜单。
- 年级、班级、学生、教师、学科、考试和成绩基础管理。
- SQLite 本地数据库、文件存储、备份/恢复和最近 30 个备份管理。
- 成绩导入预览、差异确认、缺考/未选科状态、考试级科目/满分/计总分配置、批次记录和撤销第一版。
- 年级/班级/学生分析、教师任教班级对比、历次考试对比、进退步、临界生、偏科和学生个人 Excel 导出。
- 学科独立分析及通用 Excel/PDF 报告第一版。
- 高中 3+1+2 选科组合历史和赋分规则配置框架；赋分计算暂停。
- 初中综合素质评价六学期导入、九下名单范围、五维累计分、缺失确认、等级建议、教师复核、锁定和导出第一版。
- 学生学习状态和跟进记录第一版。

## 4. 已明确暂缓或不属于范围

- 不恢复首页、登录、权限、多人协作、问卷、错题/题库、兴趣院校等模块。
- 不主动增加免考、缓考、作弊、违纪状态。
- 高中赋分具体政策、计算群体和最终算法等待学校规则，不从示例数据推断。
- 不上传真实学生数据；GitHub 只保存源码、配置、文档和脱敏测试资产。
