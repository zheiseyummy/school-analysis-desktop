# 罗曼高中智慧校园学情分析系统
# 单机本地化桌面版需求与完成状态总表

更新时间：2026-09-24

本文把当前已有需求、代码实际完成情况和仍未完成事项放在同一处，作为后续开发交接基线。

状态含义：

- **已确认需求**：用户已经明确提出或确认的目标，不代表已经开发完成。
- **已完成**：当前工作区已经实现，并有代码检查或测试证据。
- **进行中/未完成**：目标已确认，但当前版本尚未实现完整闭环。
- **待确认**：没有足够业务信息，不能自行假设实现。

## 一、项目定位与运行目标

### 已确认需求

- 仅供个人使用，不需要多人协作、账号、权限和登录密码。
- 目标平台为 Windows 10/11。
- 最终交付 Windows EXE，优先绿色便携、双击运行。
- 最终完全本地化、可离线使用；学生信息和成绩不能上传网络。
- 用户不应单独安装 MySQL、Redis、MinIO、JDK、Node.js、Tomcat 等开发或服务器环境。
- 优先采用 Vue 3 + Tauri + SQLite；不优先改用 Electron。
- 尽量保留现有 Vue 3 + Element Plus 界面和交互风格。

### 当前状态

- 当前仍是 Vue + Spring Boot 的过渡开发工程，不是最终 EXE。
- 后端当前默认使用本地 SQLite `data/school.db`；文件上传已切换为本地 `files/` 目录，但 MySQL/MinIO/OSS 过渡依赖及部分历史 SQL 尚未清理。
- SQLite 初始化、目录创建和核心表结构已完成；Tauri、自动备份恢复和绿色 EXE 尚未完成。

## 二、现有业务范围

### 已确认需要保留的核心业务

- 年级、班级、学科、学生基础资料。
- 教师资料、任教学科、任教班级和任教关系变化。
- 学年、学期、考试和历史考试归档。
- 成绩 Excel 导入、校验、修改、重新导入、查询和导出。
- 班级、年级、学生成绩分析。
- 教师教学诊断，但不用于教师考核评分。
- 学生历史成绩、班级/年级排名、单科趋势、优势/薄弱学科、偏科和进退步分析。
- 学生备注、学习状态、特殊情况和跟进记录，逐步替代复杂学情档案。
- Excel、PDF 报告导出。
- 本地自动备份、手动备份和恢复，默认建议保留最近 30 个备份。

### 初高中学段规则

- 年级增加学段属性：初中或高中；基础资料、考试、成绩和通用分析可以共用，分科和志向模块按学段启用。
- 初中学科包括语文、数学、英语、物理、化学、生物、道德与法治、历史、地理、体育。
- 每场考试导入成绩前可以自行选择考试科目；每个考试科目可以单独设置满分，初高中均适用。
- 初中不启用物理/历史选科方向、高考志向和 985/211 志向模块，但保留总分、学科、教师、班级、年级、趋势、进退步、偏科和临界生分析。

### 新增确认的分析要求

- 年级总体分析增加任课教师分析：支持教师任教班级横向比较、任教班级与年级均分/优秀率/及格率比较、历次考试趋势，以及教师多个班级的汇总结果。
- 班级学科分析支持与上一次考试比较，也支持用户任意选择两次考试比较。
- 班级相对年级的进退步定义为：本班本学科指标变化减去年级本学科同指标变化；至少覆盖均分、优秀率、及格率和班级排名。
- 增加教师所教班级差异预警、班级学科落后预警、班级偏科分析、学科成绩分布/箱线图、临界生人数和班级进退步榜。

### 明确不属于范围

- 多人账号、RBAC、数据权限、JWT、在线用户体系。
- 考试排考、考试安排、阅卷和小题得分分析。
- 跨校联考排名。
- 依赖互联网、云数据库、云同步或远程日志的核心功能。

## 三、当前已完成的改造

### 界面、路由与启动

- 保留 Sidebar、Navbar、Breadcrumb、TagsView、主题、图标、表格、表单、弹窗和现有页面风格。
- 固定业务菜单已保留：
  - 基础信息：年级、班级、学生、教师资料、学科。
  - 成绩管理：考试、成绩录入。
  - 学情分析：年级、班级、学生。
- 已移除首页路由、首页菜单和首页组件，启动后直接进入“年级管理”。
- 未知路径返回 404，404 页面可返回年级管理。
- 直接双击 `frontend/index.html` 时会提示不能使用 `file://` 打开；项目根目录提供 `启动本地前端.bat`。
- 前端开发服务仅监听 `127.0.0.1:3000`，生产预览仅监听 `127.0.0.1:4173`。

### 单用户和外围模块精简

- 已移除前端登录、密码重置、动态菜单、按钮权限和 Token 请求逻辑。
- 已清理问卷、错题/题库、兴趣爱好、目标院校、监护人、岗位、RBAC、在线演示等外围源码和 API。
- 已清理前端 Mock 及无引用的网络/编辑器依赖。
- 学生和教师保留学号/工号、姓名、性别、状态、生日、电话、头像、备注等资料。
- 学生保留班级年度归属；教师保留任教关系。
- 账号、密码列仅为旧 MySQL 表结构兼容，不再由页面填写、读取或返回接口。

### 后端和安全边界

- 已移除 JWT、Spring Security、Redis、Redisson、验证码、XXL-Job、WebSocket 演示和 Knife4j 等依赖链。
- 后端服务绑定 `127.0.0.1:8989`。
- 对请求 Host 和 Origin 做本机限制，拒绝跨站简单请求和 DNS 重绑定访问。
- 已修正学生班级年度关联保存，避免同一学生连续两年同班时覆盖历史记录。
- 未分班学生可以主动添加班级；不再自动提交空壳关系。
- 学生更新时不传班级列表会保留原关系，显式空列表才清除；无效关系进入事务回滚。
- 学生/教师性别维持必填，生日允许为空；避免与旧表 NOT NULL 字段和导入逻辑冲突。

### 工程和验证

- 已恢复前端、后端和构建配置，提供项目内便携 JDK 17 和 Maven 工具。
- `pnpm typecheck` 通过。
- `pnpm build:prod` 通过，生产构建转换 2502 个模块。
- `node scripts/check-contracts.mjs` 通过：153 个本地导入、74 个 API 适配器、12 个控制器，0 个静态错误。
- 真实 Chrome 默认业务页检查通过：0 个未捕获非 API 异常；后端未启动时的接口错误已单独记录，不冒充业务联调通过。
- 后端在线及离线 `verify` 均通过：185 个生产 Java 文件、20 个测试，0 失败、0 错误。
- 后端 JAR 位于 `backend/target/youlai-boot.jar`，仅为过渡开发产物，不是最终 EXE。

## 四、已确认但尚未完成的功能

### 初中综合素质评价

- **已完成基础**：SQLite 已增加五个评价维度、六学期原始评价、学期名单、最终评定锁定和最终结果表；已加入 A/B/C/N/A 录入值和六学期累计赋分规则。
- **尚未完成**：综合素质 Excel 六工作表导入、学生自动匹配、九下最终名单、五维班级排名、A/B/C 自动分档、教师复核、锁定/解锁、综合素质总表导出，以及初中前端菜单和页面。
- **当前边界**：数据表和评分工具已经建立，但综合素质模块还不能作为完整业务功能使用。

### 数据层和离线运行

- 将 MySQL 迁移为 `data/school.db` SQLite 数据库。
- 完成 SQLite 初始化、迁移、索引、外键和历史数据结构。
- 将 MinIO/OSS 上传改为受控的本地 `files/` 目录。
- 实现 `data/`、`files/`、`backup/`、`export/` 的本地目录管理和路径安全。
- 实现自动备份、立即备份、恢复前确认、恢复后校验和最近 30 个备份管理。
- 确保最终用户无需安装 Java、Node、MySQL、MinIO 等环境。

### 成绩导入和考试归档

- 支持 Excel 自动识别表头、数据区、学号、姓名和科目列。
- 支持多工作表、合并单元格及学校实际模板的识别确认流程。
- 支持每次考试独立保存满分、计入总分科目、原始分/赋分等配置。
- 导入前后校验总分差异，并由用户确认是否采用。
- 支持手动修改、重新导入、变更预览、修改记录和撤销。
- 处理空白、缺考、未选科、特殊数字和正常 0 分的区分。
- 保留转班、转入、转出和任教关系生效时间，使历史考试使用当时归属。

### 学情分析

- 首页数据仪表盘尚未实现；当前没有首页。
- 进退步、历史快照、单科趋势、优势/薄弱/偏科、临界生分析尚未完成。
- 高中选科组合、物理类/历史类口径和跨考试比较尚未完成。
- 学生备注、学习状态、特殊情况和跟进记录尚未形成完整业务模块。
- 教师均分、及格率、优秀率、分数段、年级差距和历次进退步诊断尚未统一实现。
- 当前保留的原分析接口和统计口径不能视为已经符合新需求。

### 报告和桌面打包

- 学生、班级、年级和教师 Excel/PDF 报告尚未按最终模板实现。
- 批量报告、命名规则、目录结构和打包方式尚未确定。
- Tauri Rust Command、应用数据目录、更新/日志策略和 Windows EXE 尚未实现。
- 尚未在没有开发环境的新 Windows 电脑上完成离线验收。

- 高中赋分的政策规则、适用年级、具体科目和计算学生群体。

## 六、当前限制和风险

- 当前版本仍依赖本机 MySQL 和过渡文件服务，不满足最终完全离线交付条件。
- 原学生、教师、班级删除逻辑仍可能影响历史成绩、任教关系和档案；SQLite 迁移时应改为停用/归档并增加引用保护。
- 原 SQL 文件包含初始化/演示内容，尚未作为新系统数据库安装脚本使用。
- 需求文档中提到的学校样表和报告模板并不等于已经完成导入/报告开发。
- 当前名称仍为“初中学情分析系统”，不代表已经完成初高中全部业务支持。
- 当前工作区已创建并推送 Git 提交 `e29e324`、`99fd830`；原始 ZIP 和接续前备份仍保留。
