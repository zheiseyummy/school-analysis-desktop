更新时间：2026-09-24

本文把当前已有需求、代码实际完成情况和仍未完成事项放在同一处，作为后续开发交接基线。

状态含义：

- **已确认需求**：用户已经明确提出或确认的目标，不代表已经开发完成。
- **已完成**：当前工作区已经实现，并有代码检查或测试证据。
- **进行中/未完成**：目标已确认，但当前版本尚未实现完整闭环。
- **待确认**：没有足够业务信息，不能自行假设实现。

## 当前同步快照（2026-09-24）

当前本地 `master` 已完成第一阶段的单用户精简、SQLite 初始化、本地文件与备份、初中综合素质评价第一版，以及年级/班级/学生分析增强。当前开发服务使用 `127.0.0.1:3000` 前端和 `127.0.0.1:8989` 后端，数据使用 `backend/data/school.db`。本地演示库已写入 1 个初中年级、1 个班级、10 名学生、10 门学科和 2 场考试。

已验证：`npm run typecheck`、`npm run build:prod`、Maven 打包和 `node scripts/check-contracts.mjs`。尚未完成：学校实际样表全链路联调、缺考/导入变更确认闭环、考试级计分配置、高中赋分、学生备注跟进、正式报告模板、Tauri 和 Windows EXE。本文后续章节的状态均以此快照为基准。

## 一、项目定位与运行目标

### 已确认需求

- 仅供个人使用，不需要多人协作、账号、权限和登录密码。
- 目标平台为 Windows 10/11。
- 最终交付 Windows EXE，优先绿色便携、双击运行。
- 最终完全本地化、可离线使用；学生信息和成绩不能上传网络。
- 用户不应单独安装 MySQL、Redis、MinIO、JDK、Node.js、Tomcat 等开发或服务器环境。
- 优先采用 Vue 3 + Tauri + SQLite；不优先改用 Electron。
- 尽量保留现有 Vue 3 + Element Plus 界面和交互风格。

### 当前状态

- 当前仍是 Vue + Spring Boot 的过渡开发工程，不是最终 EXE。
- 后端当前默认使用本地 SQLite `data/school.db`；文件上传已切换为本地 `files/` 目录，但 MySQL/MinIO/OSS 过渡依赖及部分历史 SQL 尚未清理。
- SQLite 初始化、目录创建和核心表结构已完成；自动备份、立即备份、恢复确认和备份管理页面已完成第一版；Tauri 和绿色 EXE 尚未完成。

## 二、现有业务范围

### 已确认需要保留的核心业务

- 年级、班级、学科、学生基础资料。
- 教师资料、任教学科、任教班级和任教关系变化。
- 学年、学期、考试和历史考试归档。
- 成绩 Excel 导入、校验、修改、重新导入、查询和导出。
- 班级、年级、学生成绩分析。
- 教师教学诊断，但不用于教师考核评分。
- 学生历史成绩、班级/年级排名、单科趋势、优势/薄弱学科、偏科和进退步分析。
- 学生备注、学习状态、特殊情况和跟进记录，逐步替代复杂学情档案。
- Excel、PDF 报告导出。
- 本地自动备份、手动备份和恢复，默认建议保留最近 30 个备份。

### 初高中学段规则

- 年级增加学段属性：初中或高中；基础资料、考试、成绩和通用分析可以共用，分科和志向模块按学段启用。
- 初中学科包括语文、数学、英语、物理、化学、生物、道德与法治、历史、地理、体育。
- 每场考试导入成绩前可以自行选择考试科目；每个考试科目可以单独设置满分，初高中均适用。
- 初中不启用物理/历史选科方向、高考志向和 985/211 志向模块，但保留总分、学科、教师、班级、年级、趋势、进退步、偏科和临界生分析。

### 新增确认的分析要求

- 年级总体分析增加任课教师分析：支持教师任教班级横向比较、任教班级与年级均分/优秀率/及格率比较、历次考试趋势，以及教师多个班级的汇总结果。
- 班级学科分析支持与上一次考试比较，也支持用户任意选择两次考试比较。
- 班级相对年级的进退步定义为：本班本学科指标变化减去年级本学科同指标变化；至少覆盖均分、优秀率、及格率和班级排名。
- 增加教师所教班级差异预警、班级学科落后预警、班级偏科分析、学科成绩分布/箱线图、临界生人数和班级进退步榜。

### 明确不属于范围

- 多人账号、RBAC、数据权限、JWT、在线用户体系。
- 考试排考、考试安排、阅卷和小题得分分析。
- 跨校联考排名。
- 依赖互联网、云数据库、云同步或远程日志的核心功能。

## 三、当前已完成的改造

### 界面、路由与启动

- 保留 Sidebar、Navbar、Breadcrumb、TagsView、主题、图标、表格、表单、弹窗和现有页面风格。
- 固定业务菜单已保留：
  - 基础信息：年级、班级、学生、教师资料、学科。
  - 成绩管理：考试、成绩录入。
  - 学情分析：年级、班级、学生。
- 已移除首页路由、首页菜单和首页组件，启动后直接进入“年级管理”。
- 未知路径返回 404，404 页面可返回年级管理。
- 直接双击 `frontend/index.html` 时会提示不能使用 `file://` 打开；项目根目录提供 `启动本地前端.bat`。
- 前端开发服务仅监听 `127.0.0.1:3000`，生产预览仅监听 `127.0.0.1:4173`。

### 单用户和外围模块精简

- 已移除前端登录、密码重置、动态菜单、按钮权限和 Token 请求逻辑。
- 已清理问卷、错题/题库、兴趣爱好、目标院校、监护人、岗位、RBAC、在线演示等外围源码和 API。
- 已清理前端 Mock 及无引用的网络/编辑器依赖。
- 学生和教师保留学号/工号、姓名、性别、状态、生日、电话、头像、备注等资料。
- 学生保留班级年度归属；教师保留任教关系。
- 账号、密码列仅为旧 MySQL 表结构兼容，不再由页面填写、读取或返回接口。

### 后端和安全边界

- 已移除 JWT、Spring Security、Redis、Redisson、验证码、XXL-Job、WebSocket 演示和 Knife4j 等依赖链。
- 后端服务绑定 `127.0.0.1:8989`。
- 对请求 Host 和 Origin 做本机限制，拒绝跨站简单请求和 DNS 重绑定访问。
- 已修正学生班级年度关联保存，避免同一学生连续两年同班时覆盖历史记录。
- 未分班学生可以主动添加班级；不再自动提交空壳关系。
- 学生更新时不传班级列表会保留原关系，显式空列表才清除；无效关系进入事务回滚。
- 学生/教师性别维持必填，生日允许为空；避免与旧表 NOT NULL 字段和导入逻辑冲突。
